# Campus Safety Dashboard 🚨

A simple campus safety web application designed to help students quickly access emergency contacts, medical support, safety information, and important campus resources.

## 🌐 Live Website

https://knavamis.github.io/Campus-Safety-dashboard/

## ✨ Features

- 🚨 Quick Emergency Help
- 📞 Emergency contact numbers
- 🏥 Medical Help information
- 🔥 Fire & Safety information
- 🛡️ Campus Security information
- 📍 Safe Locations
- 🔐 Safety Tips
- 🕐 Live date and time
- 📱 Responsive design for mobile devices
- ☰ Interactive navigation menu

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## 🎯 Purpose

The purpose of this project is to provide students with a simple and accessible platform for finding safety information and emergency resources on campus.
